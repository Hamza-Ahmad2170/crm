## Customers feature — full CRUD table (feature-based structure)

Mirror Kiranism's `features/<name>/` layout, adapted to your stack (Hono RPC `apiClient`, TanStack Query, Base UI shadcn primitives). Table uses `useReactTable` with local pagination/sorting state (NOT porting Kiranism's full URL-synced `useDataTable` infra — that's a separate, larger port; easy to upgrade to later).

### Dependencies to add (`apps/web`)
- `react-hook-form`, `@hookform/resolvers` — shadcn-standard form (using this instead of Kiranism's TanStack Form wrapper; simpler for a 5-field form)
- `sonner` — toasts for mutation feedback

### Phase 2 — `src/features/customers/`
5. **`api/types.ts`** — `Customer`, `CustomerFilters` (`{ page, limit, search? }`), `CustomersListResponse`. Inferred from the `apiClient.customers.$get` response type so it stays in sync with the API.
6. **`api/queries.ts`** — `customerKeys` factory + `customersQueryOptions(filters)` calling `apiClient.customers.$get({ query })`.
7. **`api/mutations.ts`** — `create/update/deleteCustomer` as `mutationOptions` that invalidate `customerKeys.all` on success (via `useQueryClient`).
8. **`schemas/customer.ts`** — form schema; reuses `createCustomerSchema` from `@repo/schema` + a `status` field for edit.
9. **`components/customers-table/columns.tsx`** — `ColumnDef<Customer>[]`: name, phone, cnic, address, status (Badge), createdAt (formatted), actions.
10. **`components/customers-table/index.tsx`** — `useQuery(customersQueryOptions)` with `placeholderData: keepPreviousData` + `useReactTable` (local pagination/sorting state) + renders shadcn table rows via `flexRender`; Skeleton rows while loading.
11. **`components/customers-table/cell-action.tsx`** — row DropdownMenu (Update → opens form sheet; Delete → confirm Dialog → delete mutation w/ toast).
12. **`components/customer-form-sheet.tsx`** — create/edit `<Sheet>` form (react-hook-form + zod resolver), create + update mutations, toasts, close-on-success. Exposes a trigger button for the page header.
13. **`components/customer-listing.tsx`** — composes a small toolbar (search Input + Add Customer trigger) above the table.
14. **`index.ts`** — barrel re-exports.

### Phase 3 — route
15. **`routes/dashboard/customers.tsx`** — replace the stub `<div/>` with `<PageContainer pageTitle="Customers" pageHeaderAction={<AddCustomerTrigger/>}><CustomerListing/></PageContainer>`.

### Notes / deviations from Kiranism (intentional, reversible)
- **react-hook-form** instead of Kiranism's `useAppForm` (TanStack Form) wrapper — less bespoke infra for a simple form.
- **local table state** instead of URL-synced `validateSearch` + `useDataTable` — avoids a 10-file shared-infra port; URL sync can be layered on later.
- `useQuery` + `keepPreviousData` for smooth pagination (Kiranism uses `useSuspenseQuery`).
- Row actions + create/edit/delete wired to the API's existing POST/PATCH/DELETE.
